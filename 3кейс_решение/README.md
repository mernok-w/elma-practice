# Синаптик. Как пользователи впервые покупают подписку

В выгрузке 136 006 заказов. У 19 284 аккаунтов обнаружена хотя бы одна оплаченная покупка с положительной суммой вне триала. За единицу анализа взят аккаунт. Каждый покупатель учитывается один раз независимо от количества продлений.

## Гипотеза 1. Большинство первых покупок происходит после триала

У 12 437 из 19 284 покупателей (64,5 %) перед первой наблюдаемой покупкой был успешно оплаченный заказ с флагом триала. У остальных 6 847 (35,5 %) такого заказа ранее в журнале не обнаружено. Медианный интервал от создания первого такого заказа до создания первой покупки составил 3,00 дня.

Гипотеза поддерживается для наблюдаемых покупателей. Доля 64,5 % описывает историю тех, кто купил подписку. Чтобы измерить конверсию из триала, понадобится другая выборка, включающая всех начавших триал. Продолжительность бесплатного использования до покупки по заказам тоже определить нельзя.

## Гипотеза 2. Большинство покупателей начинают с тарифа Lite

| Тариф первой покупки | Аккаунты | Доля |
|---|---:|---:|
| Lite | 17 818 | 92,4 % |
| Silver | 1 361 | 7,1 % |
| Gold | 92 | 0,5 % |
| Diamond | 13 | 0,1 % |

Округление долей выполнено отдельно для каждой строки. Данные поддерживают гипотезу о концентрации первых покупок на Lite. Причину выбора по заказам определить нельзя. Для проверки влияния цены или положения тарифа на экране нужны данные о показах предложений.

## Метод и воспроизведение

Из [дампа владельца сервиса](https://disk.yandex.ru/d/UYuFNCrHvWR3DQ) нужны orders.csv, product.csv и одноимённые файлы из db_structure. Сохраните их с этой структурой и выполните `python3 analyze.py "/путь/к/дампу"`. [Код анализа](analyze.py) читает заголовки из схемы, проверяет уникальность заказов и сопоставляет product_id со справочником. Для покупки применены условия status=paid, trial=f и amount>0. Предшествующий триал должен принадлежать тому же user_id, иметь status=paid, trial=t и более раннее created_at. Время соответствует созданию заказа. Первая покупка определяется в пределах доступной истории аккаунта. Один человек мог пользоваться несколькими аккаунтами.

Для подготовки кода и текста использовался ИИ. Числа рассчитаны по выгрузке. Сумма покупателей по четырём тарифам совпала с числом аккаунтов с покупкой.
